# «Пословица VS ИИ» — многостраничный сайт

## Страницы проекта

- `index.html` — главная, ежедневная пословица и общий прогресс.
- `catalog.html` — каталог из 113 записей: поиск, 8 тематических фильтров, примеры, оговорки, избранное.
- `practice.html` — тренажёр с тремя уровнями, подсказками и самопроверкой.
- `ai.html` — мастерская с генеративным Workers AI и передачей выбранной карточки в контекст модели.
- `method.html` — пошаговый разбор пословицы на конкретном примере.
- `book.html` — просмотр и скачивание полной 100-страничной книги.
- `saved.html` — полка избранного.

База находится в `data/proverbs.json` и подключена в сайт как `js/proverb-data.js`. У каждой записи — ID, тема, толкование, пример и граница применения. Избранные записи и выполненные уровни сохраняются в localStorage браузера.

## Публикация на GitHub Pages

1. Создай public GitHub repository.
2. Загрузи **всё содержимое этой папки** в корень репозитория: страницы HTML, папки `css/`, `js/`, `data/`, `assets/`.
3. В Settings → Pages выбери публикацию из `main` и папки `/(root)`.
4. Дождись адреса GitHub Pages.

## Подключение ИИ

Создай отдельный Cloudflare Worker из второго архива и укажи его точный адрес в одной строке `AI_API_URL` файла `js/ai.js`. В Worker задай `ALLOWED_ORIGIN` как `https://ИМЯ.github.io` (без пути репозитория). Полные шаги есть в README внутри архива Worker. Пока Worker не опубликован, реального ответа ИИ нет — URL заранее не выдуман. После настройки посетителям сайта ничего вводить не нужно.
